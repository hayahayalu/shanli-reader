# 山梨阅读器

极简本地电子书阅读器。界面就是一个干净的方框，**所有功能都收在右键菜单里**。

支持 `txt` / `epub`，底色任意可调（含完全透明），窗口可一路缩到很小，
内置**单行阅读**模式——窗口压成一行字，滚轮逐行翻动。

## 默认外观

打开就是一个小方框（**400 × 200**），不挡事：

| 项 | 默认值 |
| --- | --- |
| 窗口尺寸 | 400 × 200（居中） |
| 底色 | **完全透明**（只剩文字浮在桌面上） |
| 文字 | 米白 `#e8e4dc` + 一层暗色投影（深浅壁纸下都读得清） |
| 字号 | **14px**（单行阅读同样 14px） |
| 行距 / 字体 | 1.6 / 系统默认 |

窗口边界是一圈「深色外描边 + 浅色内描边」的方框，壁纸明暗都能看清；
不想要就在右键 → 方框边框 里关掉，窗口会彻底隐形。

## 启动

双击 **`启动阅读器.bat`**，或在项目目录执行：

```bash
npm start
```

> 首次使用需先安装依赖：`npm install`
> （若下载 Electron 超时，先设置国内镜像：
> `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`）

## 打包成 exe

```bash
npm run build:exe
```

产物在 `dist/`：

| 文件 | 说明 |
| --- | --- |
| `山梨阅读器-0.1.0-便携版.exe` | **单文件**，双击即用，不安装、不写注册表 |
| `山梨阅读器-0.1.0-安装版.exe` | NSIS 安装包：自选安装目录，建桌面 / 开始菜单快捷方式 |
| `win-unpacked/` | 未压缩的完整程序目录（调试用，也便于验证） |

其他用法：

```bash
npm run build:exe -- --portable   # 只出便携版（单文件）
npm run build:dir                 # 只生成解包目录，最快
```

`tools/build-exe.js` 会替你做掉两件在国内网络下必须做的事：把 `electronDist`
指向本地 `node_modules/electron/dist`（否则 electron-builder 会去 GitHub 重新拖
一份约 100MB 的 Electron 运行时），以及把 nsis / winCodeSign 工具镜像切到 npmmirror。

### 验证打包产物

「打包成功」不等于「能跑」——asar 里的路径、preload 桥、图标、内置 GBK 表，
都要等窗口真的渲染出来才算数。

```bash
npm run verify:build              # 验证 win-unpacked
npm run verify:build -- --portable
```

它会启动产物里的 exe，让应用自己把关键状态写成 JSON 后退出，再逐项断言：
打包模式、窗口标题、400×200、窗口已显示、preload 桥可用、渲染层结构、
默认全透明底、14px 字号、文字投影、图标能否从 asar 里读出、内置 GBK 表可用、
渲染层无报错。

> 这个自检入口是 `main.js` 里的 `SHANLI_SELFCHECK` 环境变量，
> 正常双击启动时不会执行到，对用户完全透明。

## 怎么用

界面里没有按钮、没有工具栏，只有文字。**在阅读区任意位置点右键**，所有入口都在那里。

| 操作 | 方式 |
| --- | --- |
| 导入书籍 | 右键 → 导入书籍…（或 `Ctrl+O`） |
| 翻页 | 滚轮 / `←` `→` / `空格` / `PgUp` `PgDn` / 点左右边缘 |
| 跳到某处 | 右键 → 跳转至…（或 `Ctrl+G`） |
| 目录 | 右键 → 目录（或 `Ctrl+T`） |
| 单行阅读 | 右键 → 单行阅读（或 `Ctrl+L`） |
| 换底色 | 右键 → 底色 |
| 改窗口大小 | 右键 → 窗口尺寸，或直接拖窗口边缘 |
| 移动窗口 | 在文字上按住左键拖动（有选中文字时不会误拖） |
| 关于 | 右键 → 关于山梨阅读器 |
| 退出 | 右键 → 退出阅读器（或 `Ctrl+Q`） |

### 跳转至（续读用）

不保存历史，所以续读靠手动跳一次。输入框支持三种写法：

- `12` 或 `12章` → 跳到第 12 章
- `480` → 跳到第 480 页
- `36%` → 跳到全书 36% 处
- 直接输入章节标题里的几个字（如 `第3章 风起`）也能定位

菜单里还预置了 25% / 50% / 75% 的快捷项。

### 单行阅读

进入后窗口自动压到**一行文字的高度**，文字横向不换行。

- 滚轮上/下 = 上一行 / 下一行
- `Esc` 退出，或右键 → 退出单行阅读
- 单行字号可在右键 →「单行字号」里调（窗口高度会跟着变）
- 窗口宽度决定每行能放多少字，横向拉宽即可多看几个字
- **翻页没有任何过渡动画**：每次只走一行，任何位移或淡入都会看成「文字在抖」，
  所以这里是刻意直接换字（`integration-test` 有断言锁住）

配合「窗口置顶」使用，就是一个常驻屏幕角落的提词器。

### 图标

`assets/icon.ico` 是 9 档尺寸的 Windows 图标（16/20/24/32/40/48/64/128/256），
`assets/icon.png` 是 256 的通用版本，设计稿在 `assets/icon.html`（纯 SVG）。
窗口、任务栏、打包（electron-builder）用的都是它。

图形：深色圆角方盘（＝桌面上那个方框窗口）+ 盘心一只熟透的梨（＝「山梨」），
梨背后一圈暖色光晕；梗和叶是「不是灯泡也不是苹果」的关键，小尺寸下也保留。

改图标只要改设计稿再跑：

```bash
npm run icon     # 逐档重新渲染 → assets/icon.ico + PNG + preview/icon-sizes.png
```

- 每个尺寸**单独光栅化一次**，不是缩放同一张位图——16px 下才认得出是个梨
- 小尺寸会切换成简化几何（加粗梗、缩短梗、换更胖的叶子、去掉高光与叶脉），
  规则写在设计稿的 `ICON_TIERS` 里
- `preview/icon-sizes.png` 是尺寸对照图：上排 1:1，下排 6× 放大，用来看小尺寸还剩多少信息

### 底色与透明度

右键 → 底色，可选预设色，也可以：

- **自定取色…** — 打开内置取色器（色相/饱和度面板、HEX、RGB、30 个预设色）
- **完全透明 0%** — 底色全透明，只剩文字浮在桌面上（默认就是这一档）
- 文字颜色可选预设，或选「深色文字（跟随底色反转）」按亮度自动配
- **文字投影** — 透明底 + 米白字时的可读性保险，可在右键 → 文字颜色 里关掉

两个防呆处理：

- 底色是全透明时点一个实色预设，会自动把不透明度提到 100%，否则你会以为没反应
- 底色变成不透明且与文字亮度太接近时（例如米白字 + 纯白底），会自动配成对比色

> 完全透明时，建议同时设「窗口置顶」，否则文字容易被别的窗口盖住。
> 桌面壁纸偏浅时，米白字靠投影才立得住；实在不好读就换成「墨黑」文字或加一点底色不透明度。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 外壳 | Electron 31（无边框 + 透明原生窗口） |
| 渲染 | 原生 HTML / CSS / JS，零框架 |
| 解析 | `adm-zip` 解 EPUB，其余全部自研 |
| 编码 | Node `TextDecoder` + 内置 GB18030 映射表 |

### 实现要点

**字符级分页引擎**（`renderer/renderer.js`）
用一个离屏量尺元素二分测量「当前可视高度能放下多少字符」，再向前回退到最近的
段落/句末标点处断开，避免句子被拦腰截断。分页按需懒生成，长书不卡。

**单行模式用「行表」而不是字符偏移推算**
单行下的行边界会随宽度变化，如果每次靠「偏移 + N」推算，前进再后退会累积漂移。
所以改为一次性把书预切成行起点数组 `lineStarts[]`，前进 = `index+1`，后退 = `index-1`，
天然严格可逆（测试覆盖 18 个位置 + 25 行往返，误差均为 0）。

单行模式还有两条必须守住的约束，否则会出现「上一行和下一行接不上」：

1. **行宽必须实测。** 正文左右内边距是被 `syncContentPadding()` 用**内联样式**写上去的，
   优先级高于 CSS 里的 `body.single .content{padding:…}`。所以量行宽时不能假设
   「窗口宽 − 24」，只能读 `内容盒实际宽度`。之前就是这里差了 28px，
   每一行末尾都被裁掉，读起来前后不接。
2. **文本要 1:1 规范化。** 单行渲染不能做「连续空白压成一个 / 去首尾空格」，
   否则「量出来的那一行宽度」与「渲染出来的那一行宽度」不一致。
   所以 `loadBook` 里会额外生成一份 `S.flatLine`：与 `S.flat` **等长、同下标**，
   只把换行/制表符逐个换成空格，测量和渲染都读它。
3. **行表要覆盖到「下一行的终点」。** 第 k 行 = `[a[k], a[k+1])`，
   若 `a[k+1]` 还没算出来就渲染，`end` 会被兜底成全书末尾，
   那一行就会把整本书的剩余部分当内容。所以前进前必须先补出目标行的终点。

**编码探测**
BOM → UTF-16 启发式 → 严格 UTF-8 校验 → GB18030 回退。GB18030 映射表
（21,791 条）已内置为 `lib/gbk.json`，中文 txt 不会乱码。
测试用的 GBK 样本也用这张表反查编码生成，整个测试链不依赖 Python 等外部工具。

**极小窗口自适应**
窗口被压得比一行还矮时，会自动收缩正文内边距，保证至少放得下一行文字，
否则会退化成一页一个字。

## 目录结构

```
main.js                       主进程：窗口、IPC、单行模式变形、取色器窗口
menu.js                       右键菜单的全部定义（功能入口集中在这里）
preload.js                    渲染层安全桥
lib/book-parser.js            txt / epub 解析、编码探测、章节切分
lib/gbk.json                  GB18030 映射表
renderer/index.html           阅读界面结构
renderer/style.css            方框、底色、单行模式样式
renderer/renderer.js          分页引擎、单行模式、跳转、主题
renderer/color-picker.*       自绘取色器
assets/icon.html              图标设计稿（纯 SVG，小尺寸另有一套几何）
assets/icon.ico / icon.png    应用图标（npm run icon 生成，任务栏/打包都用它）
assets/png/icon-*.png         每档尺寸的原始渲染结果
preview/shot-*.png            外观预览图（npm run shot 生成，含 2× 放大）
preview/icon-sizes.png        图标尺寸对照图（1:1 + 6× 放大）
tools/run-electron.js         启动 Electron 的包装（清 ELECTRON_RUN_AS_NODE / NODE_OPTIONS）
tools/preview-shot.js         外观预览截图（400×200 三种状态，铺假壁纸看可读性）
tools/make-icon.js            图标生成（逐档渲染 → PNG + 多尺寸 ICO）
tools/make-test-books.js      生成 txt / epub 测试书籍（纯 Node，含 GBK）
tools/build-exe.js            打包 exe（指向本地 Electron 运行时 + 国内镜像）
tools/verify-build.js         验证打包产物真能启动（读应用自己写的自检报告）
tools/*.js                    各测试套件
dist/                         打包产物（npm run build:exe 生成）
```

## 测试

```bash
npm run test:all   # 一次跑完下面全部（会先自动生成测试书籍）
```

单独跑：

```bash
npm test                # 解析器单测（29 项：编码 / 章节 / EPUB / 目录）
npm run test:smoke      # 分页引擎冒烟测试（含极小窗口）
npm run test:line       # 单行阅读可逆性专项（18 个位置 + 25 行往返）
npm run test:line-join  # 单行「行与行衔接」专项（不溢出 / 无空隙 / 文字不丢）
npm run test:line-resize# 单行在窗口宽度变化后的重排正确性
npm run test:app        # 端到端集成测试（导入、翻页、单行、底色、跳转、菜单）
npm run test:boot       # 启动自检（直接加载真实 main.js，验证 400×200 / 透明底 / 描边 / 图标）
npm run shot            # 外观预览截图（400×200 三种状态 + 2× 放大）
npm run icon            # 重新生成应用图标（9 档 ICO + PNG + 尺寸对照图）
npm run build:exe       # 打包成 Windows 可执行文件（安装版 + 便携版）
npm run verify:build    # 验证打包产物真能启动（需先 build）
```

> `test:boot` 是唯一会真的把窗口弹出来一下的套件（约 1.5 秒），
> 因为只有它能验证 `main.js` 里的窗口参数；其余套件都自己造隐藏窗口。

集成测试里有一项专门校验**不写入任何阅读进度/历史文件**。

> 测试脚本一律通过 `node tools/run-electron.js …` 启动 Electron。
> 本机常驻 `ELECTRON_RUN_AS_NODE=1`，直接调 `electron` 会让它退化成普通 Node、
> 窗口打不开；另外环境还注入了一个 `NODE_OPTIONS` 的 Node shim，它会被带进
> 渲染进程导致直接崩溃。包装脚本会把这两个变量都清掉。

## 已知边界

- 不保存阅读进度、不记录历史（按要求设计），续读请用「跳转至…」
- EPUB 内嵌图片不显示，只提取文字
- 4 字节 GB18030 生僻字（极少数）会显示为替换符
- 单本书上限约 400 万字，超出部分不载入
- 打包的 exe **没有代码签名**，从别处拷来第一次运行时 Windows SmartScreen 会提示
  「已保护你的电脑」，点「更多信息 → 仍要运行」即可
- 便携版每次启动要先把自身解压到临时目录，冷启动比安装版慢 1～2 秒
